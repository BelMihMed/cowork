# Калькулятор окупаемости Коворк/Код в Битрикс24

Вторая страница экосистемы калькуляторов BitrixGPT: сколько часов и денег в месяц освобождает Коворк/Код.
Считает по той же методике, что и [калькулятор BitrixGPT](https://bitrixgpt.online): ставка часа из окладов по ролям,
коэффициент реализуемости, датированные цены, единая финмодель первого года.

- Прод: https://cowork.bitrixgpt.online (GitHub Pages, ветка `main`, файл `CNAME`).
- Стейджинг: https://belmihmed.github.io/calc-stage/cowork.html (бейдж STAGING).

## Как устроен файл

`index.html` **генерируется** и руками не правится. Он собирается скриптом `build_cowork.py` из двух источников:

| Источник | Что даёт |
|---|---|
| канонический `index.html` калькулятора BitrixGPT (репо [calc](https://github.com/BelMihMed/calc)) | общее ядро: токены и базовые стили, блок «Данные о компании», глоссарий констант (`TAX`, `HOURS_MONTH`, `DAY_HOURS`, `DAYS_MONTH`, `WEEKS_MONTH`, `VAT`), финмодель `calculateEconomics`, методика реализуемости, аналитика, оболочка PDF-отчёта, модалка «i» |
| `cowork.src.html` (шаблон продукта) | задачи, роли, пресеты, коэффициенты `REAL_COWORK`, цены `COWORK_PRICE_CONFIG`, интерфейс, отчёт |

Блоки ядра обрамлены маркерами `@core:<имя> … @core:end` и в собранном файле сохраняются. Комментарий
`<!-- core: sha12 -->` в шапке — хэш вставленного ядра; тест проверяет, что он совпадает с пересчитанным,
то есть ядро в файле не правили руками и страница не отстала от канона.

Исходники сборки (`build_cowork.py`, `cowork.src.html`) и документация живут в рабочей папке проекта калькуляторов,
а не в этом репозитории.

## Тесты

```bash
npm test                          # node --test tests/*.test.mjs
deno test --allow-read tests/     # то же без node
```

Тесты читают реальный `index.html`: `glossary.test.mjs` (константы ядра, хэш, набор блоков), далее `formulas`,
`pricing`, `economics`, `scenarios`. GitHub Actions (`.github/workflows/tests.yml`) запускает их на push и pull request;
первый прогон стартует вручную (Actions → Run workflow).

## Предложить правку

Общая логика (константы, финмодель, методика) правится в каноне BitrixGPT, продуктовая — в `cowork.src.html`.
Pull request прямо в `index.html` этого репозитория будет перезаписан следующей сборкой; опишите изменение в issue.
